# 四账制度 / The Four Ledgers

> [中文 canonical]。施工总纲确立的"四账分离"纪律：**未决事项必须入账，严禁静默丢弃或伪装完成**。
> 账本实体：`literature/evidence_ledger/`，结构 `{ledger_type, description, entries[]}`。

## 入账规则

1. 校对/审计中发现**无法当场裁决**的事项，按类型入账——宁可多入，不可静默放过；
2. 每条 entry 须带定位（源 ID / PDF 页 / position）与"卡在何处"的一句话；
3. 与盲读 `[疑:A/B]`、`[残]`、`T99` 标记的关系：标记是**页面内**的存疑，台账是**跨页/跨线**
   的未决事项；页面标记可随页修复，入账事项需要专项裁决。

## 销账规则

1. 销账必须给出**依据**（图证、平行本对勘、馆藏目录等），写进销账备注；
2. 销账动作只能由对应权限方执行：M1 冻结区的问题销账须架构师裁定；
3. 严禁"批量销账"——每条独立裁决，独立留痕。
