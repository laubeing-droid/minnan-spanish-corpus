# 范围与局限声明 / Scope & Limits

本文以中文为准，说明仓库已经保存了什么，以及哪些工作仍不能算完成。内容依据移交边界文档 `literature/02_缺件与边界.md`，并结合后续施工记录更新。引用本库时，应同时说明所用版本和实际核查范围。

## 迁移与研究完成是两回事

取回一份资产、迁移一个工作区或公开一个仓库，解决的是材料保存与访问问题，不会增加学术完成数量。转写是否忠实、拟音是否有据、历史解释是否成立，仍须分别核查。

## 不能宣称的（逐条，均出自移交边界并持续有效）

1. **原计算机整个工作区**、未保存至可访问云端的文件、未取得的执行会话不在移交包内；迁移未读取用户本机其他数据。
2. **旧绝对路径引用**不保证在新机器可用；历史文档内未恢复的外部依赖须逐项确认。
3. **未对每一份历史快照做内容差量学术审查**——不保证每次试验草稿都已找到；已取得的云端资产保留，
   但"检索覆盖"不得说成"全部历史记录"。
4. **22 源三版本（原稿转写/中英释义/台罗对照）尚未全量验收**。现代台罗、历史音值、未决字形仍有
   大量工作；缺口逐条登记于四账，**不能用页覆盖率平均替代**。
5. 历史报告中曾提及的 79 个教育部官页读取等**待许可事项**属当时权限状态；本仓库发布不借此对外
   开展新的外部研究。
6. 包内标 `NOT_RUN`、候选、`PARTIAL`、未复核的程序或材料**保持原状态**；迁移与开源均未运行或
   "复活"这些材料。

## 数据发布边界（本仓库特有）

* 盲读封存件是**一过性视觉产出**，未经人工校对——引用时请注明"blind-read, pre-collation"；
* 推导层（17c IPA / MOE 台罗）是确定性引擎按规则生成，**不是音系学定论**；
* M1 主卷（5,762 条）虽在 `layer_0_visual_anchor.page_pdf` 上覆盖全部 306 页（`835–1140`），但其中 28 个批次（140 页，2,652 条）因采用 `0845.01` / `DHS1080.01` 异构 ID 导致早期按 `^DHS(\d{4})-` 审计呈现规律缺块，且主卷中 **5,106 条 `CORE` 记录在当年合龙时仅含 L 层释义（`source_H/M/R` 为空、音系层为 `sio-huê` 占位值，仅 656 条待消歧批次具完整四栏与真实音系）**——其中 140 页正由 M2 协议重做完整四栏盲读，其余 166 页 Core 条目的 H/M/R 与音系待校对线回填（详见 [LESSONS.md](LESSONS.md) L3、L20）；引用 5,762 条数时须知此结构边界；
* 现代 MOE 台罗层仅为现代参照，**严禁冒充 17 世纪历史音值**；
* **质量门为机器冗余，非人工校对（2026-11-13 用户裁定）**：本项目不设人工校对环节；
  释义层与后续派生层的把关由"K 版独立盲产 + 矩阵对碰"承担（[METHODOLOGY.md](METHODOLOGY.md)
  §6.5），复核人不通 17 世纪西班牙语是既成事实。引用时只能宣称"K 版对碰一致 +
  未决条目清单披露"，**不得表述为"已经人工校对"**；仓库内的校对工作台
  （`collation_workbench/`、`gloss_review_workbench/`）降级为可选参考材料，不是完成门；
* 源扫描件不在本仓库，语料坐标均以原 PDF 页号为准。
