# 声调几何图鉴 / Tone-Mark Geometry

> [中文 canonical]。手稿声调符按**几何形态**记录（不是按调值推断）——这是盲读协议 v3.1 的核心纪律之一。

## 一、八个合法代码

| 代码 | 形态 | 文字示意（标于元音上方） | 说明 |
| --- | --- | --- | --- |
| T00 | 無標號 | （无符） | 该音节无任何调符；须与"漏标"区分，勿自行补符 |
| T01 | 升斜 | `´`（右升斜杠） |  |
| T02 | 降斜 | `` ` ``（左降斜杠） |  |
| T03 | 尖頂帽 | `ˆ`（尖顶） |  |
| T04 | 凹角 | `ˇ`（凹角/反向尖顶） | 与 T03 形态确实相近（ˆ/ˇ 之间），难辨处记 T99 |
| T05 | 平橫 | `ˉ`（水平横线） |  |
| T06/T07 | 交叉入聲號 | `×`（两条短线交叉） | 入声标记；两形态合并记录为一码 |
| T99 | 污損難辨 | `¿`（不可判读） | 污损、残缺或形态介于两类之间 |

记录规则：`tone_marks_M` 按 M 栏该条内调符出现顺序逐个列出；`tone_marks_R` 同理对 R 栏。
手稿鼻化记号（ⁿ）不算调符，由净化器归位（见 METHODOLOGY §2）。

## 三、校对要点

1. **T03 vs T04** 是最高频的争议对：形态确在 ˆ/ˇ 之间的，宁记 T99 入账，不强判；
2. T99 聚类处理：同一手型（同一书手）的 T99 往往在同页/相邻页可借清晰例证定形；
3. 遇到非八字面（如上表"非规范"行）一律回图改码，并检查该批是否有同型漏网；
4. 调号**数与位**：校对先核对调符个数与 `tone_marks` 数组长度一致，再逐个核对形态。
