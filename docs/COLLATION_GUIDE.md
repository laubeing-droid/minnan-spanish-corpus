# 人工校对手册 / Collation Guide

> [中文 canonical]。校对线是盲读线的下游：盲读产出"所见即所录"的一过性转写，
> 校对负责逐条核对其**忠实性**（是否忠实于图），而非音系学的对错推导。
> 本文与 [DATA_SCHEMA.md](DATA_SCHEMA.md)、[TONE_MARKS.md](TONE_MARKS.md)、[LEDGERS.md](LEDGERS.md) 配套使用。

## 1. 工作清单与顺序

`literature/workspace_m2_dhs834/COLLATION_QUEUE.json`，按 `severity` 排序：

## 2. 逐页校对程式

以下是维护方获得该批数据修改授权后的流程，不是对并行施工文件的默认写权限；原盲读记录与修订版须分别保留。

1. 读该页三张横带图（必要时纵栏图），按证据需要核读；一次通过约束原盲读生产，不得取消校对阶段必要的逐字回图；
2. 对照 `blind_read_pXXXX.json` 逐条核四栏与调号**是否忠实于图**；
3. 结论三值：`忠实` / `需修（列出 position+栏位+应录值）` / `存疑（入账）`；
4. 需修项改 `raw_blind/raw_part_pXXXX.json` 后重走 commit+gatekeeper（封存件自动重生成）；
5. 存疑项按类型入四账（见 [LEDGERS.md](LEDGERS.md)），并在队列 `notes` 标注。

## 3. 裁决规范

| 标记 | 裁决要点 |
| --- | --- |
| `[疑:A/B]` | 回图定夺：能定则删除标记、保留正字；不能定则保留标记并转 `ledger_1_unresolved_glyphs` |
| `[残]` | 图上确因虫蛀/污损不可辨 → 保持；若实为可辨而读者员懒标 → 补录并记入事故备注 |
| `T99` | 重看该调符几何形态；能归类改标准码，不能归类保留 T99 先记形态辨认未决；涉及音值解释再关联 `ledger_2_unproven_phonology` |
| 页码估算 | 对比相邻页页脚推算；能定则改 `historical_folio` 并去 `estimated` 标记 |
| 串行错位 | 四栏错行（A 行西语配 B 行汉字）→ 整行重排；属读者员事故，随页重commit |

**禁止**：以现代音韵知识"改正"原稿字面（如把手稿 `ttz-` "纠正"为 `ch-`）——字面忠实性归校对，
音系解释归推导层与音系学家。
