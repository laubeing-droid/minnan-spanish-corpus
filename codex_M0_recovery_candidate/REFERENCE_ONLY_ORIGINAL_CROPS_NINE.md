## 运行和限制

```powershell
python -B -X utf8 codex_M0_recovery_candidate/test_original_crops_candidate.py
python -B -X utf8 codex_M0_recovery_candidate/grade_original_crops_candidate.py <先封存的答卷.json>
```

【修改位置】此前用数组长度判页眉和直接以严格 soup 判对错的候选程序。

【修改内容】只将首项文本规范化后确为 `ante` 且有六行视为含页眉；首项不是 `ante` 且有五行时，若首项不残缺，或按 `[残]` 实际位置补任何内容均不能构成 `ante`，则候选视为不含页眉。例如 `hi[残]ū` 和 `a[残]n` 不可能补成 `ante`；`[残]` 和 `a[残]e` 则仍有页眉歧义，A 组待核。该判断只读取首项可见字母及残段位置，不据题目参考值凑行。B 按原提示的逐行契约允许七条或八条，不以末行内容筛选；其他数量整组待核。D 数量非两条时整组待核。这些仅为符合原提示逐行输出、没有漏行或多行的前提下的候选对齐，**长度本身不证明行序**；如有漏行、多行或偏移迹象，必须人工核对，不按答案内容凑行。

逐条显示原始严格 `soup` 值。候选比较将每个 `[残]` 仅在其原位置视作未知片段，每个 `ᶜ` 或组合 `ͨ` 各自可计为字母 `c` 或不计；如果任何组合可能与参考一致，该项待核，若均不可能一致则标“与候选参考分歧”。例如 `錯[残]皮` 不可能补成 `割皮`，但 `割[残]皮` 可以；这些只比较答卷文本和候选参考，不代判真实笔迹。仅 B7 的 `ŋ/ng` 按既有参考冲突列待核，其他题不推广。汉字去空白后同理处理；整行缺答为待核。结果分别给已确定一致数和包含待核项的可能上限，按 ≥8/9 且汉字 2/2 输出候选达标、候选未达标或待核；均不作为正式放行。C 图两端截断，只展示原答，不纳入门槛、不强行判错。

【修正原因】独立审计指出原程序可能将 A 漏页眉加多行错位，并把上置组合符、部分残缺或鼻尾写法直接当成确定错误；后续审计进一步指出 B 末行不能按残字符号筛选，且上置符无论是否计入均不匹配时仍可判分歧；再次复核发现残段的位置和多个上置符分别取舍会改变可匹配性。原 `literature/tools/grade_calibration.py`、原标准与真实答卷均未改。修订后的自测只用合成答卷，33/33 项通过；两份旧盲卷的只读复核见 `REFERENCE_ONLY_ORIGINAL_CROPS_REVIEW_20261118.md`。测试成绩不是模型成绩。
