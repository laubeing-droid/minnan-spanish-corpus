`summary.json` 为汇总，`candidate_sources.json` 为候选来源，`candidate_targets.json` 为全部 12,588 个现行 `[空]`/`[残]` 目标及候选来源组，`note_anchors.json` 为备注中可提取的汉字行号线索。候选来源的 `v1_source`、`rr_source`、页号、position、重读数组序号和两份原文供复核；音写声调原样保留。汉字不明、重复来源、无来源和音节组冲突均保留记录。

来源取自首次提交重读文件之前的 Git 快照 `66b1a45^` 与现有 `reread_mr`，按 M、R 分开筛选。只有逐页行数相等、相同数组序号、历史 V1 与现行 H 的完整汉字串相同且音写字母汤相同的条目才列作**候选**；这些条件并不能证明同行。声调及音节拆分均须另核；122 条来源的两份音写音节分段不同，已在来源记录中标记。候选中的拉丁字母也可能含西语旁注。`notes` 的行号不是定位证明：p0550 备注称第 5 行为“跋卦”，历史 V1 中该汉字串唯一出现于 position 20。
